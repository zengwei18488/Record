后面保活参考如下说明，设置配置文件档
CHECK_INTERVAL: 
# Used for delay time of "main program module" loop
# Can be changed according to specific requirements
# Default 8h
PING_INTERVALS:
# Used for delay time of "frequency maintenance module" check network,
# Can be changed according to specific requirements
 # Unit must be second
 # Default : 60 1200 3600 3600
PING_INTERVAL_NORMAL：
# The period when the network is normal
# 10 minutes by default 
# Default 10m
MAX_SIM_ERROR_COUNT：
# Used for trigger 4G module frequency clearing of "SIM card maintenance module",
# Can be changed according to specific requirements 
# Default 4
MAX_PING_ERROR_COUNT：
# Used for Record the number of network check failures in "frequency maintenance module",
# Can be changed according to specific requirements
# Default 3 3 5 12
MAX_FREQUENCY_ERROR_COUNT_MIN：
# Minimum value of 4G module frequency clearing of "frequency maintenance module",
# Can be changed according to specific requirements 
# Default 3
MAX_FREQUENCY_ERROR_COUNT_MAX：
# Max value of 4G module frequency clearing of "frequency maintenance module",
# Can be changed according to specific requirements
# Default 5
MAX_LOG_SIZE
# The maximum log file size limit saved in storage, unit KiB 
# Default 100
Description of time gradient
When the frequency check network is abnormal, enter the gradient check network state
according to the default configuration in “cellular_env_docker”
Time gradient of ping network : 60 1200 3600 3600 (seconds)
Time limit of ping fail : 3 3 5 12
Minimum value of maximum error times of frequency point check : 3
Maximum value of maximum error times of frequency point check: 5
For example :
Cellular start up is in “fitst gradient”.
First time “reset modem” happen caused by network error, then form “first gradient” enter “second 
gradient”

Cellular guard V2.0 import log management function.
Log file is at DIR : /mnt/data/cellular_guard/cellular_guard.log
You can change the size of log file by changing MAX_LOG_SIZE in “cellular_env_docker” .
When the log size exceeds MAX_LOG_SIZE, cellular will Clear half size of log.
